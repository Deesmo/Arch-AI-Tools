MCP Server — Model Context Protocol
Give Claude, GPT-4, Cursor, and any MCP-compatible AI instant access to all 50 Arch Tools. One install, 53 tools appear in your AI's context.
STEP 1 — INSTALL
Install the MCP package
npm install -g @deesmo/arch-tools-mcp
STEP 2 — CONFIGURE
Add to your AI client config
arch-tools-mcp --api-key YOUR_KEY
STEP 3 — CLAUDE DESKTOP
claude_desktop_config.json
{
  "mcpServers": {
    "arch-tools": {
      "command": "arch-tools-mcp",
      "env": {
        "ARCH_API_KEY": "your_key"
      }
    }
  }
}
STEP 4 — STREAMABLE HTTP
Use the hosted MCP endpoint
https://arch-tools-mcp.onrender.com/mcp
Pass Authorization: Bearer YOUR_KEY header

REST SDK — Code Examples
Integrate directly via HTTP — no SDK required. Works in any language.
JavaScript / Node.js
# No SDK needed — plain fetch works
const res = await fetch(
  'https://archtools.dev/v1/tools/search-web',
  {
    method: 'POST',
    headers: {
      'x-api-key': 'YOUR_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ query: 'AI agents' })
  }
);
const data = await res.json();
Python
# pip install requests
import requests

r = requests.post(
  'https://archtools.dev/v1/tools/search-web',
  headers={'x-api-key': 'YOUR_KEY'},
  json={'query': 'AI agents'}
)
data = r.json()
Go
# Standard library only
req, _ := http.NewRequest(
  "POST",
  "https://archtools.dev/v1/tools/search-web",
  strings.NewReader(`{"query":"AI"}`),
)
req.Header.Set("x-api-key", "YOUR_KEY")
resp, _ := http.DefaultClient.Do(req)
cURL
# Works from any terminal
curl -X POST \
  https://archtools.dev/v1/tools/search-web \
  -H "x-api-key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "AI agents"}'
