x402 Protocol

AI agents pay with USDC. Automatically.

Arch supports the x402 payment protocol. Your agent discovers tools, sees the price, pays in USDC, and calls the endpoint — no human in the loop, no wallet setup, no API key management.

  • Agent hits endpoint → receives HTTP 402 with price + wallet
  • Agent pays in USDC on Base — transaction confirmed in seconds
  • Endpoint unlocks, tool executes, result returned
  • No wallet setup on your side — all handled by the protocol
  • Fallback: traditional Stripe credits always available
