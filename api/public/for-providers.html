How x402 Payments Work

x402 is an open payment protocol backed by Coinbase. It works at the HTTP protocol level — payments are embedded in request headers, so your API can accept crypto payments without any custom integration.

// What happens when an AI agent calls your API on Arch Tools

// 1. Agent discovers your API's pricing
GET https://archtools.dev/.well-known/x402
// → Returns: accepted networks, assets, and per-tool pricing

// 2. Agent constructs payment and calls your tool
POST https://archtools.dev/v1/tools/your-tool-name
Headers:
  Content-Type: application/json
  X-PAYMENT: <signed x402 payment for $0.01 USDC on Base>
Body:
  { "input": "whatever your API expects" }

// 3. Arch Tools verifies payment, routes to your API, returns result
// 4. $0.00975 (97.5%) settles to your wallet
// 5. $0.00025 (2.5%) is our facilitator fee
🔓 You don't need blockchain expertise. Arch Tools handles all the x402 payment verification, on-chain settlement, and wallet management. You provide an API endpoint — we handle the payment layer. All you need is a USDC wallet address to receive payouts.

Frequently Asked Questions

Do I need to run blockchain infrastructure?

No. Arch Tools handles all x402 payment verification and settlement. You provide a standard REST API endpoint — we handle the crypto layer. All you need is a USDC wallet address (MetaMask, Coinbase Wallet, etc.) to receive payouts.

Can I keep my API listed on other platforms?

Yes. There's no exclusivity requirement. List on RapidAPI, AWS Marketplace, your own website, and Arch Tools simultaneously. We don't lock you in.

What if my API is free?

We support free tools too. If you want your API in our directory for visibility but don't want to charge, that's fine. No facilitator fee on free calls.

How do I set pricing?

You choose your per-call price. We don't dictate pricing tiers or force "Free/Pro/Ultra" structures. If your API costs $0.05 per call, that's what users pay. We take 2.5% ($0.00125) and you receive 97.5% ($0.04875).

What wallet do I need?

Any wallet that can receive USDC on Base or Polygon. MetaMask, Coinbase Wallet, Rainbow, or any EVM-compatible wallet works.

How is this different from being a facilitator myself?

You could run your own x402 facilitator — Arch Tools is open source, so you have that option. Listing with us adds: marketplace discovery, MCP server inclusion (your API appears in Claude/Cursor), our developer community, analytics, and payment handling. We earn our 2.5% by driving traffic and handling infrastructure.

What's the review process?

Submit your API details via email. We review for reliability, documentation quality, and relevance. If accepted, we'll work with you to integrate it into the directory. Typical turnaround: 48 hours from submission to live listing.

Is the code open source?

Yes. Arch Tools is MIT licensed. You can review the facilitator code, the directory, and the payment handling. Transparency is core to how we build trust with providers.
