How x402 Works
HTTP-native payments in 4 steps
The x402 protocol turns HTTP 402 into a real payment flow. Your agent pays in USDC — no human needed.
Step 01
📡
Agent Calls Tool
Normal POST request to any tool endpoint. No API key, no auth header needed.
→
Step 02
💳
HTTP 402 Returned
Server returns the price in USDC, wallet address, network, and token contract.
→
Step 03
🔐
Agent Pays USDC
Agent signs a USDC transfer on Base (or 14 other chains) and retries with X-Payment header.
→
Step 04
✅
Tool Executes
Payment verified, tool runs, result returned. Done in <2 seconds. No human involved.
