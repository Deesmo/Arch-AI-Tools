How x402 Payments Work

    

      

        

          
📡

          
1. Request

          
Agent calls a tool endpoint with no API key. Just a normal HTTP POST.

        

        

          
💳

          
2. 402 Response

          
Server returns HTTP 402 with payment details: amount, wallet address, chain, token.

        

        

          
🔐

          
3. Sign & Retry

          
Agent signs a USDC payment and retries with the X-Payment header.

        

        

          
✅

          
4. Result

          
Server verifies payment, executes the tool, and returns the result. Done in <2 seconds.
