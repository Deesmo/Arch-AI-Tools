How x402 Payments Work

When your AI agent calls an Arch Tools endpoint without pre-purchased credits, it receives an HTTP 402 response containing the USDC price and wallet address. The agent signs a payment on Base, includes the receipt, and retries — the tool executes automatically.

  • Agent calls endpoint → gets 402 with price
  • Agent pays in USDC on Base → ~2 second settlement
  • Agent retries with payment proof → tool executes
  • No human approval needed at any step
  • Works across all 63 Arch Tools

Manual USDC Purchase (Fallback)

If you prefer not to use Coinbase Onramp, you can acquire USDC on Base through any of these methods:

  • Buy USDC on Coinbase and withdraw to Base
  • Buy on any exchange (Binance, Kraken, etc.) and bridge to Base via the Base Bridge
  • Swap ETH for USDC on Base using Uniswap
  • Use any DEX aggregator (1inch, Paraswap) on Base network
