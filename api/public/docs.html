API Reference

53 production tools. One API key. Every request is authenticated, credit-deducted, and logged.

Base URL: https://arch-ai-tools.onrender.com  ·  Also available at: https://archtools.dev

Authentication

Pass your API key in the x-api-key header (or as Authorization: Bearer <key>). You can get a key at archtools.dev/signup.

# Pass as header
curl -X POST https://archtools.dev/v1/tools/generate-hash \
  -H "x-api-key: arch_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"text":"hello","algorithm":"sha256"}'

Quickstart

Register, get your key, make your first call in under 60 seconds:

# 1. Register (get key instantly, no email verify)
curl -X POST https://archtools.dev/v1/agent/register \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","plan":"free"}'

# 2. Call a tool
curl -X POST https://archtools.dev/v1/tools/ai-generate \
  -H "x-api-key: arch_<your_key>" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Summarize what Arch Tools does in one sentence"}'

ChatGPT Custom GPT Actions

Connect Arch Tools to a Custom GPT in the ChatGPT GPT Store (requires OpenAI account):

  1. Go to chat.openai.com/gpts/editor → Create
  2. Click Actions → Import from URL
  3. Paste: https://arch-ai-tools.onrender.com/openapi.json
  4. Set auth: API Key → header name x-api-key
  5. Save and publish — your GPT now has 18 core Arch Tools natively

Grok & Gemini (API function calling)

Both xAI (Grok) and Google (Gemini) support function calling via their APIs. Pass the Arch Tools OpenAPI spec or define tool functions manually. No consumer app connector stores exist yet for either platform — use the REST API directly in your agent code. The openapi.json at https://arch-ai-tools.onrender.com/openapi.json has all parameter definitions.

PowerShell

Invoke-RestMethod -Uri "https://arch-ai-tools.onrender.com/v1/tools/web-scrape" `
  -Method POST `
  -Headers @{ "x-api-key" = "arch_your_key_here"; "Content-Type" = "application/json" } `
  -Body '{"url":"https://example.com"}'

Node.js (fetch)

const res = await fetch('https://arch-ai-tools.onrender.com/v1/tools/web-scrape', {
  method: 'POST',
  headers: {
    'x-api-key': 'arch_your_key_here',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ url: 'https://example.com' })
});
const data = await res.json();
console.log(data);

Python

import requests

res = requests.post(
    "https://arch-ai-tools.onrender.com/v1/tools/web-scrape",
    headers={"x-api-key": "arch_your_key_here"},
    json={"url": "https://example.com"}
)
print(res.json())
